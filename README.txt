📋 INSTRUÇÕES PARA FAZER DEPLOY - PDI MIRAE
===========================================

🎯 RESUMO DO QUE FAZER:

1. Download todos os 4 arquivos desta pasta do Google Drive:
   - index.html ✅ (CORRIGIDO)
   - manifest.json ✅
   - sw.js ✅
   - firebase.json ✅

2. Coloque os 4 arquivos em: C:\mirae-app

3. Abra Terminal/PowerShell nessa pasta

4. Digite o comando:
   firebase deploy

5. Pronto! Seu app estará em https://pdimirae.web.app
